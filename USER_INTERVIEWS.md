# USER INTERVIEWS

## Interview 1

### User Type
Startup Founder

### Pain Points
- High AI subscription costs
- Multiple unused AI tools
- Lack of visibility into spending

### Feedback
The user wanted a simple dashboard that could identify unnecessary subscriptions and suggest cheaper alternatives.

---

## Interview 2

### User Type
Freelancer

### Pain Points
- Paying for multiple AI tools simultaneously
- Unsure which tools provide the best value

### Feedback
The user preferred an easy-to-use audit system with clear savings recommendations.

---

## Interview 3

### User Type
Small Development Team

### Pain Points
- Overpaying for enterprise AI plans
- Managing team-based subscriptions

### Feedback
The team wanted analytics and optimization scoring to help make better subscription decisions.

---

## Common Insights

- Users want spending transparency
- Users prefer automated recommendations
- Startups are highly cost-sensitive
- Simplicity and clear UI are important
