# AI Spend Audit

AI Spend Audit is a SaaS-style web application that helps startups identify unnecessary spending on AI tools and optimize software costs.

## Features

- AI tool spending analysis
- Savings recommendations
- Monthly and annual savings calculations
- Optimization scoring
- Risk analysis
- Interactive analytics dashboard
- Downloadable audit reports
- Persistent form state using localStorage

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Recharts
- React

## Setup

```bash
npm install
npm run dev

```
